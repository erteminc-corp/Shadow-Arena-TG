SHADOW ARENA: ASHFALL

Допоміжна сторінка для публікації з iPhone. Тут немає полів для токена бота. BOT_TOKEN додавай лише до Secrets Cloudflare.

1. Код Cloudflare Worker

Натисни «Скопіювати». Якщо Safari не дозволяє буфер обміну — торкнися коду, «Вибрати все» → «Копіювати».

2. Публічна конфігурація гри

Встав тільки HTTPS-адресу Worker, наприклад https://ashfall-stars.username.workers.dev. Це не секрет.

Завантажений файл заміни в GitHub через Upload files. Якщо iPhone додав до назви (1), спочатку перейменуй на config.js у «Файлах».
